# AG_CONTEXT.md

- **Project**: apple-podcast-transcript-extractor (macOS)
- **Purpose**: CLI tool to extract Apple Podcasts transcripts; now also provides a native GUI using Tauri.
- **Structure**:
  - `extractTranscript.js` – original Node.js CLI implementation.
  - `src/` – frontend HTML/CSS/JS for the Tauri GUI.
  - `src-tauri/` – Rust backend exposing several Tauri commands:
    - `scan_episodes` – recursively discovers TTML files and fetches metadata from the Apple Podcasts SQLite DB.
    - `extract_transcript_command` – extracts a transcript (optionally with timestamps).
    - `get_transcript` – returns parsed paragraphs for a specific episode for in-app viewing. Uses a namespace-aware TTML parser for better compatibility.
    - `search_episodes_content` – performs a fast substring search across all episodes.
    - `get_default_transcript_directory` – returns platform app data directory.
    - `delete_audio` – deletes the audio file for a given episode.
  - `src-tauri/src/transcript.rs` – core logic for scanning, metadata lookup, TTML parsing (namespace-aware, robust timestamp support), and file writing.
- **Recent Fixes**:
  - Fixed Success Banner being visible on launch and non-dismissible by correcting a broken CSS rule (missing brace in `styles.css`).
  - Improved Transcript View reliability by making the TTML parser namespace-aware (handling `<tt:p>` etc.).
  - Resolved UI issues where `.hidden` class was ignored due to CSS parsing errors.
  - Fixed selection bar syntax error and listener registration issues in `main.js`.
- **Features**:
  - **In-App Viewer**: View transcript content directly within the application.
  - **Search Highlighting**: Highlights search matches within the transcript viewer when using content search.
  - **Flexible Extraction**: Extract single transcripts from the viewer or batch extract selected episodes.
    - **Timestamp Options**: Selection bar now features a split button to choose between "with" and "without" timestamps (defaulting to "with").
    - **Audio Deletion**: Delete the cached audio file for specific episodes directly from the context menu or transcript viewer. Uses native macOS Trash API (NSFileManager) for deletion.
    - **Multi-File Reveal**: Uses native macOS API (NSWorkspace) to select multiple files simultaneously in a single Finder window.
    - **Transcript Deletion**: Move extracted transcript files to Trash directly from the app.
    - **Local Transcript Source**: When a transcript is extracted, the original TTML file is copied to a local store (`.metadata/ttml/`). The app now always prioritizes this local copy for viewing, re-extraction, and searching. This ensures that once a transcript is extracted, access is preserved even if the Podcasts app deletes the original file (creating an "orphaned" episode).
  - **Entitlements**: Added `Entitlements.plist` (with sandboxing disabled) and configured `tauri.conf.json` to resolve recurring macOS permission prompts and ensure file access persistence.
  - **Explicit Folder Access**: To gain access to the Apple Podcasts data without triggering implicit permission dialogs, the app now prompts the user once with an explanation dialog before opening a folder picker. Once selected, the path is persisted.
  - **Settings Persistence**: Remembers the user's preferred output directory and Podcasts data directory (gained via explicit picker) using `tauri-plugin-store`.
  - **UX Enhancements**: 
    - Default sort set to "Podcast (A-Z)".
    - Automatic one-time tab switching to "Extracted" when no episodes remain in the "Unextracted" view (while still allowing manual navigation back).
    - "Scan for Episodes" button is replaced by a loading spinner during the scanning process for better feedback.
    - Prominent "Success Section" with large text and a primary button for opening the output folder; includes "Ok" and "Close" buttons that dismiss the large view and return the "Open Folder" action to the footer status bar.
    - Improved progress feedback with immediate bar hiding upon completion.
    - **Selection & Edit Menus**: Restored "Select All" (`Cmd+A`) to the Edit menu and added a native "Selection" menu with "Select All" and "Select None" (`Esc`) actions. Cmd+A is now context-aware: it selects all text if a text field is focused, and selects all episodes in the current list otherwise.
    - **Contextual Actions**: Selection bar now contextually hides transcript-related actions when viewing unextracted episodes.
- **Database layouts**: old (`ZMTEPISODE.ZTRANSCRIPTIDENTIFIER`) and new (macOS 27: `ZMTMEDIAENCLOSURE.ZTRANSCRIPTIDENTIFIER`, joined via `ZEPISODE` → `ZMTEPISODE.Z_PK`). Both the CLI (`buildMetadataQuery`) and Rust (`metadata_query`) check columns with PRAGMA and pick one. The DB is opened read-only.
- **Output**: `<podcast> - YYYY-MM-DD - <episode>.txt` with a Podcast/Date/Episode/Description header. `resolve_base_name` keeps a pre-0.2 undated file name if only that file exists (mirrored by `getExpectedFilename` in main.js). The app auto-scans on launch once the Podcasts folder is saved.
- **Build** (bun only, never npm):
  - `bun install`, `bun run dev`, `bun run build`.
  - `bun run test` – Rust unit tests. `FIXTURE_PODCASTS_DIR=<copied 243LU875E5… folder> cargo test -- --ignored --nocapture` runs scan + extract end to end.
  - `bun run release` – universal build, signed with the keychain's "Developer ID Application" cert, notarized, stapled, checked with spctl, zipped, attached to a DRAFT GitHub release (notes from `RELEASE_NOTES.md`). Needs a notary login in `.env`: an App Store Connect API key (`APPLE_API_ISSUER`, `APPLE_API_KEY`, `APPLE_API_KEY_PATH`, preferred) or `APPLE_ID` + `APPLE_PASSWORD` (app-specific) + `APPLE_TEAM_ID`.
  - `bun run test:reset-permissions`, `bun run test:open-app`.
- **CI**: `.github/workflows/checks.yml` runs a syntax check and cargo test on PRs and main. Releases are made locally with `bun run release`, never by CI (signing needs the keychain cert).
- **Future**: Keep CLI unchanged for scriptable usage; GUI provides a user‑friendly interface for non‑technical users.
